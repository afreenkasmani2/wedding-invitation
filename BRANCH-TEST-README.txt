OPENING ANIMATION TEST BRANCH — OPTION 1

This build uses the approved Option 1 image as the texture for two independently
rotating door halves. The mobile opening screen fills the viewport and hides the
navigation and all following sections until the visitor taps the central seal.
After the door animation, normal page scrolling is restored.

Important visual limitation:
Because Option 1 is a single flattened image, the ribbon and wax seal are part of
the door texture. This prototype uses a brief gold release glow and then swings
both halves outward; it does not physically untie the ribbon or detach the seal.

Test this only on the opening-animation-test branch. Do not merge to main until
the phone preview has been approved.
