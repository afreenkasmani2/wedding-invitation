AFREEN & IRFAN — WEDDING WEBSITE

This is a fresh, static-first version of the seven-section wedding website.
It uses the seven approved page designs supplied by you as full-page artwork.
The site is one continuous scrolling page and is responsive for phones and computers.

FILES
- index.html: website structure and section order
- style.css: layout and responsive styling
- script.js: simple date-reveal interaction
- assets/: the seven supplied page designs

PREVIEW
Open index.html in a browser. No extra software or build step is required.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload index.html, style.css, script.js, and the entire assets folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site and open the provided URL.

NOTES
- The approved artwork is currently used as page images, so lettering inside those artworks is not individually editable yet.
- The Nikah and reception map buttons are transparent clickable areas positioned over the map buttons in the supplied designs.
- The date section has a basic tap-to-reveal interaction.
- No music file was supplied, so music has not been added in this version.
- Animations can be added later without changing the overall site structure.
